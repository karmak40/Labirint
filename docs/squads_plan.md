# Отряды, построение и обучающий штурм: план

Согласовано с пользователем 2026-09-29.

## Решения пользователя
- Группы на цифрах: Ctrl+цифра запоминает, цифра выбирает, повторное нажатие наводит камеру. Карточки HUD переезжают на буквы. Предлагался ряд Q W E R T Y, но W, A, S, D двигают камеру, поэтому взят нижний ряд **Z X C V B N**.
- ПКМ без выделения посылает всю армию, как раньше.
- Обучающий уровень только боевой, без экономики.
- Обучение — комната 0 в кампании. «Лесной рубеж» тоже открыт сразу, так что обучение можно пропустить.

## Отряды
- **Выделение.** Клик по своему бойцу выбирает его. Рамка ЛКМ выбирает всех своих бойцов в ней. Shift добавляет к выделению. Двойной клик выбирает всех бойцов того же вида на экране. Клик по чужому только показывает его окно. Клик по пустой земле снимает выделение.
- **Приказы выделенным.** ПКМ — атака с движением. Кнопки «Стоять» (встать, где стоит) и «Держать позицию» (не гнаться дальше короткого поводка). Команды принимают id бойцов: `GameState.order(team, ids, kind, point)`.
- **Построение** работает в любом приказе, в том числе у ИИ. Отряд встаёт лицом к цели: впереди ближний бой (рыцари, мечники, секироносцы, двуручники, воины), за ними копейщики, поджигатели и лазутчики, позади стрелки и маги.
- **Окно отряда.** Когда выбрано несколько бойцов, окно показывает состав по видам, общее здоровье и номер группы.
- **Телефон.** Полоса кнопок «Все», «Пехота», «Стрелки» и групп 1–3: касание выбирает группу, долгое нажатие запоминает. Кнопка «Рамка»: пока она нажата, палец рисует рамку вместо движения камеры.

## Обучающий штурм (комната 0)
- **Своя армия без замка:** 3 рыцаря, 3 копейщика, 3 лучника, маг с «Исцелением», поджигатель, лазутчик.
- **Противник:** замок в тумане, 2 башни, несколько защитников. Его ИИ не играет.
- **Подсказки по шагам, каждая ждёт выполнения:** камера → выбор бойца → рамка → группа → построение → разведка лазутчиком → башня (лучники издалека, поджигатель) → лечение → штурм. Каждый шаг можно пропустить, обучение можно скрыть целиком.
- **Поражение:** погибла вся армия.
- **Звёзды:** победа, быстро, и больше половины армии осталось в живых.
